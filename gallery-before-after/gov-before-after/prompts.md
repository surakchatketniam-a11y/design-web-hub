## หลัง — แนบ DESIGN.md + tokens.css ที่ผสมจากหน้า /mix/

ให้ Gemini สร้างเว็บหน่วยงานเดิมต่อจากหน้า "ก่อน" โดยคงเลย์เอาต์เดิม แล้วใช้คำสั่งนี้ (ข้อความหลังบรรทัดแรกสร้างจากแท็บ "คำสั่งให้ AI" ของหน้า /mix/ เลือกเครื่องมือ "ทั่วไป" ใส่ชื่อเว็บ "สำนักงานใจดีพื้นที่พิจิตร")

```
ให้คุณสร้างเว็บไซต์หน่วยงานเดิม เลเอาท์เดิม เพิ่มเติมคือให้ทำตาม prompt ด้านล่างนี้ แล้วบันทึกไว้เป็น After
ฉันกำลังสร้างหน้า landing ของเว็บผลิตภัณฑ์/บริการ ช่วยออกแบบและเขียนโค้ดตามระบบดีไซน์ในไฟล์ DESIGN.md และ tokens.css
ถ้าเครื่องมือให้แนบไฟล์ได้ ให้อ่านไฟล์ DESIGN.md และ tokens.css ที่แนบมา ถ้าแนบไม่ได้ ผมจะวางเนื้อหาทั้งสองไฟล์ต่อท้ายข้อความนี้

เนื้อหาของฉัน:
- ชื่อเว็บ/ธุรกิจ: สำนักงานใจดีพื้นที่พิจิตร
ส่วนที่ต้องมี: แถบนำทาง, hero พร้อมปุ่มหลัก, จุดเด่น 3–6 ข้อ, หลักฐานทางสังคม (รีวิวหรือโลโก้ลูกค้า), ตารางราคา, FAQ และ CTA ปิดท้าย

กติกา:
1. ยึดสี ฟอนต์ รัศมีมุม ระยะห่าง และคอมโพเนนต์ตาม DESIGN.md อย่างเคร่งครัด ห้ามเพิ่มสีหรือสไตล์ที่ไม่มีในไฟล์ (ใช้ค่าจาก tokens.css)
2. อ่านส่วน Do's and Don'ts ให้ครบและทำตาม
3. ใช้ชื่อ โลโก้ และข้อความของฉันเอง — ห้ามใช้ชื่อหรือโลโก้ของ แบรนด์ที่เป็นแรงบันดาลใจ
4. รองรับมือถือ และใช้ HTML ที่เข้าถึงได้ง่าย (semantic tags, คอนทราสต์ผ่านเกณฑ์)
5. ใช้ Tailwind CSS (หรือ CSS ธรรมดา) โดยตั้งค่าจาก tokens.css
6. ถ้าเนื้อหาเป็นภาษาไทย ให้ตั้ง <html lang="th"> และใช้ฟอนต์ไทยตามส่วน Thai Typography ใน DESIGN.md (line-height เนื้อความอย่างน้อย 1.7 และห้ามใช้ letter-spacing กับตัวอักษรไทย)
7. เมื่อเสร็จ สรุปสั้นๆ ว่าตัดสินใจเรื่องดีไซน์อะไรไปบ้าง

ข้อห้ามกันหน้าตา AI ทั่วไป:
- ห้ามใช้ gradient ม่วง-น้ำเงิน หรือสีใดๆ ที่ไม่มีใน DESIGN.md
- ห้ามใช้ emoji แทนไอคอน ให้ใช้ไอคอน SVG ชุดเดียวกันทั้งหน้า
- ห้ามวางการ์ด 3 ใบเรียงกันซ้ำในทุก section ให้เปลี่ยนโครงตามเนื้อหา (ตาราง, รายการ, ภาพคู่ข้อความ, ตัวเลขเด่น)
- ห้ามใช้เงา มุมโค้ง หรือขนาดตัวอักษรที่ไม่ได้กำหนดไว้ในไฟล์
- ห้ามใช้ข้อความโฆษณากลวงๆ (เช่น “ยกระดับธุรกิจของคุณ”, “ปฏิวัติวงการ”) ห้ามใช้ lorem ipsum และห้ามแต่งตัวเลข รีวิว หรือโลโก้ลูกค้าปลอม ถ้าขาดข้อมูลให้ถามผมก่อน
```

## หมายเหตุเรื่องความโปร่งใส (ควรแสดงบนหน้าแกลเลอรี)

- ทั้งสองหน้าสร้างด้วย Gemini 3.8 Flash (High) บน Antigravity ตามที่ Gemini ระบุเอง เมื่อวันที่ 7 ต.ค. 2026 ไม่มีภาพประกอบ (ใช้ CSS และ SVG ที่โมเดลเขียนเอง)
- หน้า "หลัง" สร้างต่อจากหน้า "ก่อน" โดยสั่งให้คงหน่วยงานและเลย์เอาต์เดิม ต่างจากชุดอื่นที่แต่ละหน้าสร้างแยกกัน และคำสั่ง "หลัง" ระบุส่วนที่ต้องมีและกติกาเพิ่มเติม ความต่างจึงมาจากทั้งไฟล์ DESIGN.md คำสั่งที่ละเอียดขึ้น และการสร้างต่อจากหน้าเดิม
- หลังสร้าง ทั้งสองหน้าถูกแก้ตามข้อสังเกตของผู้ดูแลเว็บนี้ 3 ประเด็น: (1) ลบชื่อองค์กรจริงที่ถูกอ้างเป็นภาคี และข้ออ้างมาตรฐาน DGA/ITA (2) เปลี่ยนที่ตั้งและเบอร์โทรเป็นข้อมูลสมมุติ และใส่แถบเตือนว่าเป็นโครงการจำลอง ห้ามกรอกข้อมูลจริง (3) ปรับหน้า "หลัง" ให้มีระบบเท่ากับ "ก่อน" (แชทบอท แบบฟอร์ม 6 แบบ ข้อเสนอแนะ แถบการเข้าถึง) 
- ก่อนถ่ายภาพ ผู้ช่วย Claude แก้ผลงานของ Gemini ด้วยมือเล็กน้อยตามคำสั่งผู้ดูแลเว็บนี้ ไม่ได้ให้ Gemini แก้: หน้า "ก่อน" เปลี่ยนตัวเลขสถิติสมมติ (48,500+ / 3 วัน / 98.6%) เป็นข้อความจำลองชุดเดียวกับหน้า "หลัง" (100% / 3–7 วัน / 0 บาท) และตัดข้อความที่อ้างว่าเป็นระบบหรือมาตรฐานของกรมสรรพากรออก 3 จุด (ปุ่ม e-Tax, ปุ่ม e-Donation, หมายเหตุแบบฟอร์ม) หน้า "หลัง" เพิ่มกฎ CSS ที่ HTML ใช้แต่ไม่ได้นิยามไว้ (ช่องว่างเมนู gap-5 และอื่นๆ), ให้ลิงก์เมนูไม่ขึ้นบรรทัดใหม่ และให้เมนูเดสก์ท็อปแสดงเมื่อหน้าจอกว้างอย่างน้อย 1200px (จากเดิม 1040px) ไม่ได้แก้สี ฟอนต์ หรือเนื้อหาอื่น ภาพที่แสดงถ่ายหลังแก้แล้วทั้งหมด
- เว็บนี้แสดงเฉพาะภาพหน้าจอ ไม่เปิดหน้า HTML จริงของชุดนี้ เพราะในหน้ามีช่องกรอกเลขประจำตัวประชาชนจำลองและมีลักษณะคล้ายเว็บหน่วยงานรัฐ
