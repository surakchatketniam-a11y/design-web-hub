# แกลเลอรี "ก่อน–หลัง" — ชุดที่ 1: รับเหมา / ช่างไฟฟ้า

ชุดไฟล์สำหรับทำหน้าแกลเลอรีบน DESIGN.md Hub

## ไฟล์ในชุดนี้

| ไฟล์ | คืออะไร |
|---|---|
| `prompts.md` | โจทย์ร่วมและคำสั่งที่ใช้สร้างแต่ละหน้า (ควรแสดงบนหน้าแกลเลอรี) |
| `gallery.json` | ข้อมูลสำหรับ render หน้าแกลเลอรี: ป้ายชื่อ, ไฟล์ภาพ, ลิงก์ไปหน้าผสมสไตล์, หมายเหตุ |
| `before.html` | หน้า "ก่อน" — สั่ง AI โดยไม่มี DESIGN.md |
| `after-renault.html`, `after-zapier.html`, `after-ibm.html` | หน้า "หลัง" — โจทย์เดียวกัน แต่แนบ DESIGN.md + tokens.css |
| `shots/*.png` | ภาพหน้าจอ: `desktop` 1440px และ `mobile` 390px (@2x) ทั้งแบบ `fold` (หน้าจอแรก) และ `full` (ทั้งหน้า) |

## ข้อเสนอโครงหน้าแกลเลอรี (`/gallery/`)

1. **หัวหน้า:** "AI ตัวเดียวกัน โจทย์เดียวกัน ต่างกันแค่ไฟล์ DESIGN.md"
2. **ตัวเลือกชุดโจทย์:** เริ่มจากชุด "รับเหมา / ช่างไฟฟ้า" ภายหลังเพิ่มชุดอื่นตามประเภทธุรกิจในตัวช่วยแนะนำ
3. **แถวเปรียบเทียบ:** ภาพ "ก่อน" ซ้าย และภาพ "หลัง" ขวา สลับดูได้ 3 สไตล์ (แท็บหรือแถบเลื่อน)
   - มีปุ่มสลับ เดสก์ท็อป / มือถือ
   - ใช้ภาพ `fold` เป็นค่าเริ่มต้น กด "ดูทั้งหน้า" เพื่อเปิดภาพ `full`
4. **ใต้ภาพ "หลัง" แต่ละแบบ:**
   - ปุ่ม "เปิดสไตล์นี้" → `/b/<style>/`
   - ปุ่ม "ผสมต่อจากนี้" → `mix_link` ใน gallery.json
   - ปุ่ม "เปิดหน้า HTML จริง" → ไฟล์ `.html`
5. **กล่องคำสั่ง:** แสดงเนื้อหา `prompts.md` พร้อมปุ่มคัดลอก
6. **บรรทัดความโปร่งใส:** ระบุว่า AI ตัวไหนสร้าง วันที่ และสิ่งที่แก้หลังสร้าง (อยู่ใน `generator` ของ gallery.json)

ภาพ PNG ควรแปลงเป็น WebP และใส่ `loading="lazy"` ก่อนขึ้นเว็บ

## สิ่งที่เห็นได้ชัดจากการเปรียบเทียบ

| | ก่อน | หลัง |
|---|---|---|
| สี | gradient น้ำเงิน-ม่วง (หน้าตาแบบ AI ทั่วไป) | สีหลักสีเดียวตามไฟล์ เช่น เหลือง / ส้ม / น้ำเงิน |
| ฟอนต์ไทย | Prompt (AI เลือกเอง) | ตามส่วน Thai Typography: Anuphan / IBM Plex Sans Thai |
| ไอคอน | emoji | SVG เส้นเรียบ |
| โครงหน้า | การ์ดมุมโค้ง + เงา ซ้ำทุก section | แต่ละสไตล์มีโครงของตัวเอง เช่น ไทลส์เหลี่ยม, bento, ตาราง |

## ข้อจำกัดที่ควรรู้

- ทั้ง 4 หน้าสร้างโดย Claude ซึ่งเป็น AI ตัวเดียวกับที่ช่วยรีวิวเว็บนี้ ถ้าต้องการหลักฐานที่น่าเชื่อถือกว่านี้ ทีมควรสั่งซ้ำด้วยเครื่องมืออื่น (ChatGPT, Cursor, Lovable, v0) ด้วยคำสั่งใน `prompts.md` แล้วเพิ่มเป็นแถวในแกลเลอรี
- ภาพหน้าจอเรนเดอร์ด้วยฟอนต์จริงจากแพ็กเกจ Fontsource (ชุดเดียวกับ Google Fonts) เพราะเครื่องที่ใช้แคปเข้าถึง Google Fonts ไม่ได้ ไฟล์ HTML ยังโหลดจาก Google Fonts ตามปกติ
- ไม่มีรูปถ่าย ใช้กราฟิก SVG แทนตามโจทย์

## ข้อสังเกตเพิ่มเติม

ตัวช่วยแนะนำบนหน้าแรก เมื่อเลือก "รับเหมา / ช่าง" จะแนะนำ BMW, HP และ IBM ซึ่ง **เป็นโทนน้ำเงินองค์กรทั้งสามแบบ** ผู้ใช้จึงได้ตัวเลือกที่หน้าตาคล้ายกันเอง
- **แนะนำ:** ให้ผลลัพธ์กระจายโทนสีอย่างน้อย 1 แบบ เช่น ใส่ Renault (เหลือง-ดำ ซึ่งเข้ากับงานไฟฟ้า) หรือ Zapier (ครีม-ส้ม อบอุ่น)
- ชุดแกลเลอรีนี้จึงเลือก Renault และ Zapier มาเทียบกับ IBM
