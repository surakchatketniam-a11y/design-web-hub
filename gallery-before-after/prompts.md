# คำสั่งที่ใช้สร้างแกลเลอรี "ก่อน–หลัง"

ทุกหน้าใช้ **โจทย์เดียวกัน** (ส่วน "โจทย์ร่วม") ต่างกันแค่ว่าแนบ DESIGN.md หรือไม่
"ช่างไฟใจดี" เป็นร้านสมมติ เบอร์โทร/LINE/ตัวเลขทั้งหมดเป็นข้อมูลตัวอย่าง

## โจทย์ร่วม

```
สร้างหน้า landing page (HTML ไฟล์เดียว, CSS ในไฟล์) สำหรับ "ช่างไฟใจดี"
ร้านรับเหมางานไฟฟ้าในบ้านและอาคาร พื้นที่นนทบุรี ปทุมธานี และกรุงเทพฯ ฝั่งเหนือ
เนื้อหาภาษาไทยทั้งหมด ประกอบด้วย:
1. เมนูด้านบน + hero พร้อมปุ่ม "โทรเลย" และ "แอดไลน์"
2. ตัวเลขความน่าเชื่อถือ 4 ตัว (งานที่ทำเสร็จ, ปีประสบการณ์, รับประกันงาน, เวลาตอบกลับ)
3. บริการ 6 อย่าง: เดินสายไฟใหม่, ตรวจระบบไฟ/หาไฟรั่ว, ติดตั้งโซลาร์เซลล์,
   ติดตั้งเครื่องชาร์จรถ EV, ขอเพิ่มขนาดมิเตอร์, ซ่อมด่วน 24 ชม.
4. ขั้นตอนการทำงาน 4 ขั้น
5. ผลงานที่ผ่านมา 3 งาน
6. คำถามที่พบบ่อย 4 ข้อ
7. ฟอร์มขอใบเสนอราคา (ชื่อ, เบอร์โทร, ประเภทงาน, รายละเอียด) + footer
ไม่มีรูปถ่าย ให้ใช้รูปทรง/กราฟิกด้วย CSS หรือ SVG แทน
```

## ก่อน — ไม่มี DESIGN.md (`before.html`)

```
[โจทย์ร่วม]
ออกแบบให้สวย ทันสมัย ดูน่าเชื่อถือ
```

## หลัง — แนบ DESIGN.md (`after-renault.html`, `after-zapier.html`, `after-ibm.html`)

ใช้คำสั่งรูปแบบเดียวกับแท็บ "คำสั่งให้ AI" บนเว็บ แล้วแนบไฟล์ของสไตล์นั้น

```
[โจทย์ร่วม]
อ่าน DESIGN.md และ tokens.css ที่แนบมา แล้วออกแบบตามนั้นอย่างเคร่งครัด
- ใช้เฉพาะสี ฟอนต์ มุมโค้ง ระยะห่าง และเงาที่กำหนดในไฟล์ ห้ามเพิ่มสีที่ไม่มีในไฟล์
- ทำตาม Do's and Don'ts และส่วน Thai Typography
- ห้ามใช้ emoji แทนไอคอน ใช้ SVG เส้นเรียบแทน
- ห้ามวางการ์ดเรียงกันแบบเดิมซ้ำทุก section
```

| ไฟล์ | สไตล์ที่แนบ | ไฟล์ต้นทาง |
|---|---|---|
| after-renault.html | Renault (เหลือง Sunlight + ขาวดำ มุมเหลี่ยม) | `/d/renault/DESIGN.md`, `/d/renault/tokens.css` |
| after-zapier.html | Zapier (ครีมอุ่น + ส้ม มุม 12px) | `/d/zapier/DESIGN.md`, `/d/zapier/tokens.css` |
| after-ibm.html | IBM (หนึ่งในสไตล์ที่ตัวช่วยแนะนำสำหรับ "รับเหมา / ช่าง") | `/d/ibm/DESIGN.md`, `/d/ibm/tokens.css` |

## หมายเหตุเรื่องความโปร่งใส (ควรแสดงบนหน้าแกลเลอรี)

- ทั้ง 4 หน้าสร้างโดย AI ตัวเดียวกัน (Claude) ในรอบเดียว ต่างกันแค่การแนบ DESIGN.md
- หลังสร้างแก้ 1 จุด: หน้า Zapier มีช่องว่างในกริดบริการ จึงขยายการ์ด "ขอเพิ่มขนาดมิเตอร์" ให้เต็มแถว (ไม่ได้เปลี่ยนสีหรือฟอนต์)
- ฟอนต์ไทยในหน้า "หลัง" มาจากส่วน Thai Typography ที่เว็บเพิ่มเข้าไปในไฟล์
